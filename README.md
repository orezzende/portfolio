# Portfólio — Daniel Rezende

Site estático preparado para publicação no **GitHub Pages**.

## Arquivos
- `index.html` — portfólio completo.
- `curriculo.pdf` — currículo usado pelos botões de visualização e download.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (por exemplo, `portfolio`).
2. Envie `index.html` e `curriculo.pdf` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço ficará parecido com `https://SEU-USUARIO.github.io/portfolio/`.

## Observações
- Não renomeie `index.html`: ele é a página inicial do GitHub Pages.
- Mantenha `curriculo.pdf` na mesma pasta do `index.html`.
- As imagens das telas dos projetos já estão incorporadas ao HTML; não é necessário enviar uma pasta de imagens.
- Os links de demonstração e repositórios continuam apontando para `orezzende.github.io` e `github.com/orezzende`, conforme configurado no arquivo original.
